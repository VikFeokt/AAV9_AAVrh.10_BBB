# AAV9_AAVrh.10_BBB
This repository contains data and scripts supporting the manuscript "Differential Central Nervous System Transduction by Adeno-Associated Viruses and the Structural Stability of Their Receptor Complexes: An Integrated In Vivo and In Silico Study".

# Contents 
'FoldX' - FoldX results for AAV9 and AAVrh.10
'Molecular_dynamics' - input files for MD simulations and their analysis
'HADDOCK' - input and output files for HADDOCK
'Figures' - figures in svg and png formats
'PyMol' - some representative PyMol sessions 

# Code authorship and repository role
This repository contains data and computational materials supporting the results of the associated manuscript and represents the collective work of the study co-authors. The repository is maintained to ensure transparency and reproducibility of the published results.
